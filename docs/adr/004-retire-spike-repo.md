# ADR-004: 退役前置 spike 仓，框架事实唯一来源改为本仓探针

- 日期：2026-09-02
- 状态：已接受（修订 ADR-001 决策 2、ADR-002 后果第一条）

## 背景

ADR-001 决策 2 采用 spike-then-rewrite 双仓形态：前置 spike 仓沉淀框架映射结论，本仓按结论重写。ADR-002 随之要求"spike 仓结论引用前须在本仓版本上逐条复核"。

两点事实使该形态失去价值：其一，该 spike 仓早期即已停止维护，其结论产自 langchain-core 1.4.9 世代，与本仓基线（langchain-core 1.6.1 / langgraph 1.2.11）相隔多个版本；其二，ADR-002 已确立"框架 API 用前必 inspect/探针实测"纪律，本仓探针本身就是框架事实的直接来源。经过"逐条复核"的 spike 结论与直接探针结果等价，spike 仓不再提供增量信息，反而引入过时世代的记忆风险。

## 决策

1. **spike 仓退役**：不再作为任何里程碑设计稿、ADR 或测试的输入；ADR-001 决策 2 的双仓形态终止，本仓为唯一工程仓。
2. **框架事实唯一来源=本仓探针**：探针脚本按需编写并运行于本仓锁定的依赖版本，结论逐条写入对应 ADR 的实证节；语义权威仍为 v1.0 冻结仓的行为契约，工程模板仍为 Argus。
3. **差距记账表从零建立**：以 v1 行为契约清单为行，各里程碑设计稿逐行裁决（保留/降级近似/放弃），不继承 spike 仓账本。

## 后果

- ADR-002 后果第一条中"spike 仓结论引用前须逐条复核"失效，保留其后半句"框架 API 用前必 inspect/探针实测，不凭记忆写码"作为唯一纪律。
- ADR-001 背景与 ADR-002 背景中对 spike 仓的描述保留为历史记录，不回改。ADR-002 首例实证（GenericFakeChatModel.bind_tools 抛 NotImplementedError）已在本仓版本上独立验证，结论不受本决策影响。
- 探针脚本本身不入库；入库的是 ADR 中的结论与复现步骤。
